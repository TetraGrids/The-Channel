## Description
Interact with local p2p network connections.

## Command

```console
Usage: chan net SUBCOMMAND
```

## Subcommands

 - [chan net connect](connect.md) start a new connection to a peer

 - [chan net disconnect](disconnect.md) close an existing connection

 - [chan net status](status.md) status of existing connection

 - [chan net peers](peers.md) status of all existing peers
