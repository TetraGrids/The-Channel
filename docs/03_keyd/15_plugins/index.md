## Overview

Plugins extend the core functionality implemented in `keyd`. For information on specific plugins, just select from the list below:

* [`http_plugin`](../../01_channeld/03_plugins/http_plugin/index.md)
* [`wallet_api_plugin`](wallet_api_plugin/index.md)
* [`wallet_plugin`](wallet_plugin/index.md)

[[info | Keyd is modular]]
| Plugins add incremental functionality to `keyd`. Unlike runtime plugins, `keyd` plugins are built at compile-time.
